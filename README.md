# Simple Web Image Downloader

A lightweight Python script that scrapes a target webpage and automatically downloads all visible images into a local `images` folder.

## Prerequisites

Make sure you have Python installed on your machine.

## Installation & Setup

1. Place `download_images.py` and `requirements.txt` into the same folder.
2. Open your terminal or command prompt inside that folder.
3. Install the required dependencies by running:
   ```bash
   pip install -r requirements.txt
